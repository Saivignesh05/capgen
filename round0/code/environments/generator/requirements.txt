# ==============================================================
# Dependency conflict note
# ==============================================================
#
# descript-audiotools 0.7.4 (a transitive dependency pulled in by parler-tts via
# descript-audio-codec) declares protobuf<5.0.0 in its package metadata. It does NOT import
# protobuf at runtime: the constraint is a stale artefact from an older version that used gRPC.
# pip prints a conflict warning, but the package works correctly with protobuf 5.x.
#
# sentencepiece==0.2.1 is required. Version 0.2.3 triggers a "gencode version does not match
# runtime version" error, because it bundles protobuf generated code that is incompatible with
# the protobuf 5.x runtime.
#
# Exact versions of everything installed are recorded in requirements.lock.txt after building.
# ==============================================================
