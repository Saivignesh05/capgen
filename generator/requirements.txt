# ==============================================================
# Indic-Parler-TTS Generator
# Python 3.10 required
# ==============================================================
#
# PyTorch must be installed separately before the rest of the
# dependencies, because the correct wheel depends on your hardware:
#
#   CPU (any platform):
#     pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
#
#   Apple Silicon (MPS) – default macOS wheel includes MPS support:
#     pip install torch torchaudio
#
#   NVIDIA CUDA 12.x:
#     pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
#
# After installing PyTorch, install the remaining dependencies:
#     pip install -r requirements.txt
#
# ==============================================================
# Dependency conflict note
# ==============================================================
#
# descript-audiotools 0.7.4 (a transitive dependency pulled in by
# parler-tts via descript-audio-codec) declares protobuf<5.0.0 in
# its package metadata. However, descript-audiotools does NOT
# import protobuf at runtime – the constraint is a stale artefact
# from an older version of that library that used gRPC. pip will
# print a conflict warning but the package works correctly with
# protobuf 5.x.
#
# sentencepiece==0.2.1 is required. Version 0.2.3 triggers a
# "gencode version does not match runtime version" error because
# it bundles protobuf generated code that is incompatible with
# the protobuf 5.x runtime.
#
# ==============================================================
